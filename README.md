# 📊 Tableau Dashboards Portfolio

## 🔹 Project Overview
This repository contains multiple Tableau dashboards developed to analyze business data and provide actionable insights across different domains such as Sales, CRM, Customer Performance, and HR Analytics.

The goal of these dashboards is to transform raw data into meaningful visualizations to support data-driven decision making.

---

## 🎯 Business Objectives
- Analyze sales performance and revenue trends
- Monitor customer behavior and performance metrics
- Evaluate CRM sales pipeline insights
- Track HR performance and workforce metrics
- Identify key KPIs and business trends
